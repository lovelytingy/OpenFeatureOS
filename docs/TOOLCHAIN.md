# OpenFeatureOS Toolchain & Development Environment

## 1. Toolchain Policy

* **Target Architecture**: Single ARM Cortex-A7 core (ARMv7-A)
* **Target Flags**: `-mcpu=cortex-a7 -marm -mfpu=vfpv4-d16 -mfloat-abi=softfp`
* **Language Policy**:
  - **C (C99 / GNU99)**: Operating system core, drivers, board support, subsystems, applications.
  - **ARM Assembly (`.S`, GNU as syntax)**: Limited strictly to startup bootstrap, low-level exception vectors, context switching, and CP15 cache/MMU primitives.
  - No C++, no Rust.
* **Target Toolchain**: `arm-none-eabi-gcc` toolchain suite (`gcc`, `as`, `ld`, `objcopy`, `objdump`, `size`).

## 2. Host Installation Instructions

### macOS (Apple Silicon / Intel)
```bash
# Using Homebrew
brew install --cask gcc-arm-embedded
# Or using the open-source brew formula
brew install arm-none-eabi-gcc make python3
```

Verify the installation:
```bash
arm-none-eabi-gcc --version
# Expected: arm-none-eabi-gcc (GCC) 10.x, 11.x, 12.x, or 16.x
```

### Ubuntu / Debian Linux
```bash
sudo apt update
sudo apt install -y gcc-arm-none-eabi binutils-arm-none-eabi libnewlib-arm-none-eabi make python3
```

### Arch Linux / Fedora
```bash
# Arch Linux
sudo pacman -S arm-none-eabi-gcc arm-none-eabi-binutils arm-none-eabi-newlib make python

# Fedora
sudo dnf install arm-none-eabi-gcc-cs arm-none-eabi-newlib make python3
```

## 3. Memory & Packaging Conventions

* **Volatile DRAM Execution**:
  - Loaded address: **`0x80100000`** via USB FDL1 (`spd_dump`).
  - Header: 512-byte (`0x200`) Unisoc **`DHTB`** container generated by `scripts/mkdhtb.py`.
  - Code entry point: **`0x80100200`** (`load_addr + 0x200`).
* **Binary Artifacts**:
  - `openfeatureos.elf`: Unstripped ELF binary with debug symbols.
  - `openfeatureos.raw`: Flat binary payload stripped of ELF headers.
  - `openfeatureos.bin`: Flat binary prefixed with the 512-byte `DHTB` header, ready for DRAM loading via `spd_dump` or execution in `n2660emu`.

---

## 4. Emulator Execution

The project integrates `Nokia-2660-Emulator` as a reference submodule.
To run the built payload in the emulator:

```bash
make emu
```

This invokes:
```bash
./third_party/nokia-2660-emulator/bin/n2660emu build/openfeatureos.bin --prefer-pac --entry 0x80100200
```
